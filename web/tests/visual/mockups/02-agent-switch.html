v2 draft 02 · Agent switch inside a conversation (V2-3)

One tab switches between Claude and Codex (ACP agents later). The target agent starts in the same folder; a handoff built from the transcript waits as a chip and goes only with the user's Enter; a divider marks the switch; switching back reuses the earlier session; pending approvals stay with the session that raised them.

Prototype drafts for the owner's pick (throwaway, not shipped). Nunchiro Light tokens from web/src/styles.css; window = R8-final at compact density with today's live labels. Proposed token: --bad for problem state (styles.css already falls back to #c0392b).

Recommendation: A, segmented selector in the header. It matches the spec, keeps the heavy action (a new session) apart from the light per-send chips, shows the old agent's state in its segment, and the handoff still lands in the composer where Enter happens. Add C's rail later only if conversations with three or more switches turn out common.
