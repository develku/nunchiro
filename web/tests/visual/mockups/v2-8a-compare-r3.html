승인용 시안이며 아직 만들지 않았습니다. 현재 = 기준으로 남겨 둔 1차 모달 시안. 시안 1은 합의한 원클릭 구성입니다. 시안 2, 3은 서로 다른 아이디어를 하나씩 섞되 같은 안전 규칙을 지킵니다: 보이는 단계, 되돌리기, 확인 없이는 아무것도 잃지 않음. “by coordinator” 표시는 어디에도 없습니다. TREEROWS 토큰과 아이콘을 그대로 썼고 정적이며 네트워크를 쓰지 않습니다.
