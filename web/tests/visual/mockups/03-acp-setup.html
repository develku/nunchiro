Set up Gemini CLI

What Gemini can do here. Read and write files only inside the session folder (links out are refused). Terminals it asks for run in Nunchiro and show in the tab. Each permission request waits in the tree like Claude's; answers are Allow once or Reject once. Nunchiro stores no API key: Gemini's own login or the env names below provide it.
Approval covers exactly:
/opt/homebrew/bin/gemini --experimental-acp   env: GEMINI_API_KEY
Any change to this entry asks again.
Rationale
Detection does the work first, so the common case is Set up → read the test result → Approve; the exact command, env names and what the agent may do sit on the one sheet that is also the approval.
Trade-off
A failed check (signed out, wrong version) shows inside the same sheet, which grows long; Custom command users get the same sheet with an empty command.
A11y
Sheet is a modal dialog with aria-modal and a heading label, focus starts on Command and is trapped; check results are ✓/✗ glyphs plus words; Escape cancels.

Check Gemini CLI

✓Found /opt/homebrew/bin/gemini · 0.11.2
✓Speaks ACP v10.4 s
✗Not signed in. Gemini said: “Please set an Auth method”.
–Capabilities (after sign-in)

The login runs gemini itself in a tab you can see; come back and press Check again.

Rationale
Separates the three jobs so each screen has one decision; the check step is where things go wrong (not signed in, old version), and it gets the room to show the cause and one fix, the same shape as the problem card.
Trade-off
Three screens for what is usually a one-click success; Back/Next adds a mouse trip for keyboard users unless Enter advances.
A11y
Step pills carry text state, Next stays focusable with aria-disabled and says why; the failed row's fix button gets focus after a check run so Enter fixes.

Rationale
Follows the layout.toml rule (needs 37): the file is the truth and the GUI explains it; power users edit in their editor, the checker shows found / ACP / signed in / approved per entry and the approval sheet does the rest.
Trade-off
No in-app editing (v2 builds no file editor) so a first-time user must leave the app to add an agent; the least friendly of the three for people new to the tool.
A11y
Results are a labelled complementary region with one card per entry, state in words; the read-only file view is a focusable region with line numbers announced; clipboard action announces “Entry copied”.
