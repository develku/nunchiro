끝난 세션을 트리 밖으로: 속 빈 막대 + 옅어지는 레일 + 기록 위젯 (시안 4)

트리는 "지금 일하는 세션"만 보여 줍니다. 끝난 세션은 10분 동안만 트리에 흐리게 남고, 그 뒤 색 바 왼쪽의 속 빈 막대로 들어갑니다. 칩을 누르면 그 프로젝트의 끝난 세션이 팝오버로, "모두 보기"를 누르면 기록 위젯이 열립니다. 행 높이는 앱 그대로 28px(현재 32px에서 조금 줄임)로 그렸습니다. 색은 Nunchiro 기본 다크(회색)입니다.

0. 트리 구조: 메인 폴더 세션이 항상 맨 위, 그 아래 워크트리 (다크)

프로젝트를 펼치면 행은 두 종류입니다. 워크트리 행은 워크트리 하나가 한 행이고, 세션이 끝나도 워크트리가 있는 동안 남습니다(코드가 그 안에 있으므로). 메인 폴더 세션 행은 워크트리 없이 프로젝트 폴더에서 시작한 세션 하나가 한 행입니다. 이번 변경(속 빈 막대, 옅어지는 레일)은 메인 폴더 세션에만 적용됩니다. 워크트리 행과 "정리 가능" 접힘은 지금 그대로입니다.

규칙 요약
  • 순서프로젝트 아래에는 메인 폴더 세션 행이 항상 맨 위, 그 아래 워크트리 행, 맨 아래 "정리 가능" 접힘.
  • 범위메인 폴더 세션만. 워크트리 행은 세션이 끝나도 워크트리가 있는 동안 남고, 병합되면 "정리 가능" 접힘으로 갑니다(지금 그대로).
  • 트리살아 있는 세션만. 끝난 세션은 레일이 속 빈 막대가 되어 10분 동안 옅어지고, 그 뒤 빠집니다. 글자 배지는 없습니다.
  • 속 빈 막대색 바 왼쪽의 속 빈 막대 = 그 프로젝트에서 오늘 끝난 세션 수. 1~2개는 막대, 3개부터 막대 하나 + 숫자(색 바 규칙 3과 같음). 0이면 없습니다. 누르면 팝오버(최근 5개 + "모두 보기").
  • 기록위젯 하나에 모든 끝난 세션. 검색(대화 내용 포함), 프로젝트·에이전트·실패 필터, 대화 보기 / 이어서 하기 / 변경 보기.
  • 색 바프로젝트 행 오른쪽의 색 바(64px 칸)는 그대로입니다. 속 빈 막대는 색 바 왼쪽에 6px 띄워 붙고, 색 바 칸을 줄이거나 밀지 않습니다. 끝난 세션은 색 바에 세지 않습니다.
  • 빠지는 것"N done" 접힘 줄, 트리 안의 끝난 세션 펼침.
  • 색초록은 쓰지 않습니다. 끝난 세션은 속 빈 막대, 색은 주황(내 차례)과 빨강(실패)에만 남습니다.
  • 실패한 세션(빨강)과 내 차례(주황)는 끝난 것이 아니므로 그대로 트리에 남습니다.
기존 규칙(388, 462)과 맞춘 점
  • 색 바(실패·내 차례·stale·작업 중·쉬는 중)는 그대로. 끝난 세션은 색 바에 세지 않습니다(462 규칙 그대로).
  • 속 빈 막대는 색 바와 같은 크기·간격·규칙 3(1~2개 막대, 3개부터 막대 하나 + 숫자). 색 바 왼쪽에 붙어, 오른쪽 정렬된 기존 막대는 1px도 움직이지 않습니다.
  • 펼친 프로젝트의 색 바는 40%로 흐려지지만(388), 속 빈 막대는 흐려지지 않습니다. 끝난 세션은 아래 줄에 없기 때문입니다.
  • 접힌 그룹 머리(예: Trading)는 속한 프로젝트의 끝난 수를 합쳐 같은 규칙으로 보여 줍니다. 기기 줄에는 없습니다.
  • 올리기: 0.4초 뒤 "끝남 3 · 오늘" 한 줄. 누르기: 팝오버(388의 "색을 누르면 그 세션으로"와 달리 끝난 세션은 트리에 없으므로 목록).
  • 가장자리 모음과 ] / [ 걷기에는 끝난 세션이 들어가지 않습니다(빨강·주황만, 388 그대로).
  • 방금 끝난 행은 속 빈 막대 수에 들어가지 않고, 트리에서 빠질 때 하나 늘어납니다. 오른쪽에 쉬는 중 원 아이콘을 두지 않아 "쉬는 중"과 헷갈리지 않습니다.
  • 실패(오류로 끝남)는 빨강으로 트리에 남습니다. 사용자가 멈춘 세션은 실패가 아니라 끝난 세션(회색)입니다.
  • 오늘 기준: 속 빈 막대는 오늘 끝난 수이며 자정에 0이 됩니다. 기록 위젯에는 모두 남습니다.
