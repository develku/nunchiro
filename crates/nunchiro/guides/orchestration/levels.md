# Levels

| Level | Workers | Brief | Review | Record |
|---|---|---|---|---|
| solo | 1-2 | Goal + Own + Acceptance, inline in the prompt | you read the diff | none (the app's tree) |
| team (default) | any | brief file + REPORT.md | one fresh reviewer session per lane | app tree; REPORT.md in the worktree |
| strict | any | team brief + a Threats list (3-5 attack paths, a check each) | fresh review + security review | same as team |

Pick `strict` for code that handles permissions, credentials, sandboxes, payments or user data, even when the user named
a lower level; say so to the user.
