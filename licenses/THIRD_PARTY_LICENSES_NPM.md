# Third-party licenses: npm packages

Licence and NOTICE files of the npm packages bundled into the Nunchiro web UI. Generated by `scripts/gen-notices.sh`; do not edit by hand.

Packages: `pnpm licenses list --prod` in `web/` (164 package names, 165 name and version pairs; `app/` has only dev dependencies and ships nothing from npm).

## Shiki grammars and themes

`web/dist` carries TextMate grammar and theme chunks from @shikijs/langs 4.5.0 (360 modules), @shikijs/themes 4.5.0 (65 modules). Those packages are MIT (their own LICENSE is below), but each grammar and theme is derived from an upstream project with its own licence. The upstream licence list is not in the installed package: the `@shikijs/langs` and `@shikijs/themes` 4.5.0 tarballs carry no per-grammar licence metadata, no `tm-grammars` or `tm-themes` package is installed, and the chunks have no licence headers. It was therefore not possible to confirm from the install that every upstream grammar and theme is permissive. Follow-up: list the upstream licences from the `tm-grammars` and `tm-themes` metadata, or narrow the bundled languages and themes in `web/src/files/highlight.ts`.
